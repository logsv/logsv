## 📦 Open Source Projects

### [EM TaskFlow AI](https://github.com/logsv/em-taskflow-ai)

Full-stack, local-first engineering productivity platform using **100% local LLM inference with Ollama**, hybrid RAG with **HyDE + RRF + HNSW**, Redis semantic caching, a **LangGraph multi-agent supervisor** with 10 domain agents (DORA, delivery, sprint, OKR, retro, and more), Temporal workflows, Langfuse tracing, and MCP integrations for Jira, Notion, GitHub, Slack, and Google Calendar.

**Stack:** Node.js · Python · React · LangGraph · Ollama · PostgreSQL/pgvector · Redis · Temporal · Langfuse · MCP

### [LLM Video Editor](https://github.com/logsv/llm-video-editor)

Prompt-driven video editor for **YouTube (16:9) and Shorts/Reels (9:16)**. Point it at raw footage and describe the cut: it transcribes with faster-whisper, has an LLM plan the edit (picking segment ids, never timestamps), then runs a **deterministic audit → review → render → publish pipeline** with face-aware captions, chapters, jump-cut pacing, colour grading, ducked licensed music, optional local AI narration, -14 LUFS loudness, and an SEO upload pack with thumbnails. Works as a one-command pipeline or in **agent mode via an MCP tool server**, and footage never leaves your machine.

**Stack:** Python · FFmpeg · faster-whisper · MediaPipe · Pydantic · MCP · LangGraph · Claude / Ollama

### [India Stock Analyzer (long-ledger)](https://github.com/logsv/long-ledger)

Personal analysis workspace for long-term investors in Indian equities, run from **Claude Code**. Claude syncs holdings read-only from **Zerodha Kite and INDmoney (official MCP servers)** and 5paisa, researches companies from their official filings with source-tracked, fact-checked numbers, and explains the results, while a **deterministic, dependency-free Python core** computes every label, risk flag, allocation limit, market-regime signal, and tax figure. Strictly analysis-only: order tools are denied by design.

**Stack:** Python · SQLite · MCP · Claude Code (slash commands, subagents, guarded settings)
